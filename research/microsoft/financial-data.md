# 微软 (MSFT) 财务与行情数据

- 数据截止日：2026/07/31
- 收盘价：464.72 USD
- 市值：约 3.45 万亿美元
- 估值：PE(TTM，FY2026) 约 25.8x

## 核心指标

- FY26Q4 营收：900.1 亿美元（同比 +18%）（超预期约 2.6%）
- FY26Q4 净利润：357.7 亿美元（同比 +31%）（含 Anthropic 投资 32 亿收益）
- Azure 增速：同比 +43%（下季指引约 45%）（连续两季加速）
- 商业剩余履约义务：6,780 亿美元（同比 +84%）（剔除 OpenAI 仍 +25%）
- 单季资本开支：410 亿美元（同比 +70%）（三分之二投向 CPU/GPU）
- 自由现金流：196 亿美元（同比 -23%）（连续两季负增长）
- Copilot 付费席位：3,000 万个（上季 2,000 万）（净新增环比翻倍）
- 距 52 周高点：-5.6%（高点 492.02 美元）（财报后跳空 16%）
