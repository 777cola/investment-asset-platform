Moat anatomy: four rivers, one loop — Alphabet

Part Three: Why This River Is Deeper and Shallower Than It Looks

Core view

Four moats: default entry points (Chrome about two-thirds, Android about 70%), the data loop (Search + Maps + YouTube + Gmail), TPU vertical integration, and Gemini distribution (1 billion app users). The key is not how strong each of these four is on its own, but that they form a loop: entry points generate data, data trains models, models improve products, products defend entry points. The antitrust ruling did not dismantle any one of them; it only mandated data sharing and a choice screen — the moat was thinned slightly, but the loop remains. The real threat is not external competition, but that the "entry point" link in the loop could be bypassed by AI chat.

Rule one: the default entry point, the most underrated of them all

Chrome holds about two-thirds of global browser share, Android about 70% of global mobile operating system share, plus the default search agreement with Apple. Taken together, these three form a structure in which "users use Google even without choosing it" — the most expensive default in the world. The default search fee Apple collects from Google each year runs into the tens of billions of dollars; that money does not pay for technology, it pays rent on the gateway.

After the choice-screen obligation takes effect in April 2026, European users will be able to pick a default search engine during setup. This will erode some default traffic, but it will not change the fact that "most people will not go and change the setting." Historical precedent: the EU pushed a choice screen on Android back in 2019, and Google's search share in Europe fell by less than 3 percentage points. So the loss from this channel is measurable, not fatal.

Point two: a data flywheel that others simply cannot buy

Search queries, map locations, YouTube viewing, Gmail content, Chrome browsing behavior—this combination of five data types is unique in the world. It gives Gemini an edge over pure model companies in "personalization" and "real-world grounding": it knows where you are, what you have watched, what you have bought, and what you have asked.

But the data moat has an easily overlooked boundary: data is useful only for "improving existing products," not necessarily for "creating new products." ChatGPT lacked Google's data and still reached 1 billion users, showing that general capability matters more than personalized data. So the data moat protects search and advertising, not Gemini's competitiveness. The distinction is critical: if an AI migration occurs, the data moat cannot protect the new battleground.

Article 3 and Article 4: TPU and Gemini, one rigid, one soft

TPU is a rigid moat: it takes a decade of accumulation, TSMC capacity and a supporting software stack; rivals cannot copy it. Gemini is a soft moat: model capability is matched every six months, open-source models are still chasing, and no one holds a decisive lead. Put the two together and Alphabet's strategy is clear: use the soft asset (models) to defend the entry point, and the hard asset (chips) to make money.

The weak point of this strategy is the "soft" one. If model capability is matched and a rival holds a stronger entry point (say Apple + OpenAI), Gemini's distribution advantage gets offset. So what really matters is not "where Gemini ranks" but "whether Gemini's default distribution slot has been taken away." 1 billion app users currently show distribution is intact, but that is dynamic.

How to measure a moat: three trackable ratios

A moat cannot rest on adjectives alone; it must be trackable in numbers. First, monetization efficiency per search — the ad revenue generated by each search. If this number falls for consecutive periods, AI answers are diluting inventory and the moat is being eroded from within. Second, traffic acquisition cost as a share of search revenue — if this ratio rises, the gateway is getting more expensive (Apple raising prices, regulators mandating choice screens) and the moat is getting shallower. Third, cloud customer retention and backlog growth — high retention means switching costs are real.

Of the three ratios, the first matters most and is the least transparent: the company does not disclose revenue per search, so it can only be derived indirectly from "search revenue / third-party traffic estimates." Search grew 12% in Q3 on revenue of RMB 63.35 billion; if third-party data show query volume up 15%, then monetization efficiency per unit is declining. This is the point that needs external data verification, and it is the weakest link in this report.

The second ratio has public clues: TAC sits in cost of revenue, so it can be observed indirectly through gross margin changes. For the third ratio, watch how the backlog balance (RMB 56.1 billion in Q3) matches cloud revenue growth. Only when all three ratios deteriorate at once is the moat truly broken; one deteriorating alone is noise.

When moats actually disappear

Only three scenarios could dry up this river. ① Users fundamentally change how they ask questions—no longer typing keywords or opening Google's app, but using a system-level voice assistant. This requires Apple or Samsung to switch the default entry point, and the user experience to be markedly better. ② Regulators force open the search index and data—competitors use Google's data to build search of equal quality, directly erasing the data moat. ③ Advertisers find a more efficient substitute—not "slightly worse performance," but "twice as good," and there is currently no evidence of this.

Of the three, the second warrants the most vigilance, because it does not require users to change their habits. The choice screen and data-sharing obligations taking effect in April 2026 are the first step in this direction.

Conclusion

Moat 8.2/10: gateway 9, cost 9, network 9, switching 7, regulation 6. Three of the four moats are rigid and one is soft; the damage is measurable but not fatal. What truly needs monitoring is "whether the gateway link can be bypassed by AI conversation"—that is the moat's only structural risk.
