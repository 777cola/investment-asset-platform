## ① 看得懂（Understandability）

### 核心业务拆解

**阿里巴巴本质上是一家什么公司？**

用一个"三层漏斗"来看：

```
┌────────────────────────────────────────────────┐
│  第一层：赚钱机器（~85%利润来源）              │
│  ├─ 淘天集团（淘宝+天猫+1688）→ GMV~8万亿     │
│  ├─ 阿里云 → 国内IaaS+PaaS市场份额~34%         │
│  └─ 国际电商（Lazada/AE/Trendyol）→ 增长最快   │
├────────────────────────────────────────────────┤
│  第二层：战略资产（烧钱但必要）                │
│  ├─ 菜鸟物流 → 电商履约基础设施                │
│  ├─ 饿了么/高德 → 本地生活入口                 │
│  └─ 钉钉 → 企业服务入口                        │
├────────────────────────────────────────────────┤
│  第三层：非核心/可剥离（价值不确定）           │
│  ├─ 大文娱（优酷、阿里影业）                  │
│  ├─ 盒马/银泰/高鑫零售 → 逐步减持中           │
│  └─ 蚂蚁集团(~33%) → 股权价值被低估           │
└────────────────────────────────────────────────┘
```

### 赚钱逻辑（一句话说清楚）

> **阿里赚的是"商家税"（+云服务费）—— 商家在淘宝/天猫上做生意，要给阿里付广告费、佣金、技术服务费。阿里云则是按算力卖水卖电。**

这个商业模式类比巴菲特最爱的**收费桥（Toll Bridge）**：桥建好了，车流越多收的过路费越多。阿里的"桥"就是淘宝/天猫/阿里云的平台。

### 复杂点

- 多业务并行增加了估值难度——你不清楚每块业务值多少钱
- 子公司上市/未上市交叉持股，穿透计算复杂
- 但好消息是：管理层正在做减法——2024-2026年明确"回归核心"

### ✅ 最终判定：看得懂

**不需要懂AI大模型、不需要懂云计算架构。只需理解：阿里是中国电商的基础设施 + 云服务的基础设施。只要中国不出大问题、只要电商在增长、只要企业还在用云，阿里就能赚钱。**

## ② 护城河（Economic Moat）

### 五大护城河维度评分（1-10分）

| 维度 | 评分 | 说明 |
|------|:----:|------|
| **网络效应** | 8/10 | 10亿买家+千万级商家，双边平台飞轮仍在运转 |
| **品牌护城河** | 7/10 | 淘宝=购物，品牌心智强，但PDD"低价"心智正在侵蚀 |
| **规模优势** | 8/10 | GMV~8万亿，物流网络最广，云计算基础设施最完善 |
| **转换成本** | 7/10 | 商家迁移成本高（店铺装修/数据/ERP对接），但消费者可零成本切换到PDD/抖音 |
| **无形资产（专利/牌照）** | 6/10 | 云计算牌照、支付牌照有壁垒，但技术领先优势在缩小 |

### 护城河变化趋势（FY2022→FY2026）

```
护城河宽度： ██████████  →  ████████░░  （变窄）
```

**核心问题：阿里的护城河在加速变窄还是只是暂时被冲击？**

**看空观点（市场共识）：**
- PDD从"拼多多"变成了"全品类低价平台"，直接威胁天猫
- 抖音电商以"内容驱动"模式重新定义了电商，传统货架电商在失去年轻人
- 阿里云市场份额从2019年46%下降到2026年~34%

**看多观点（逆向思考）：**
- 拼多多的利润开始增速放缓（FY2025增速从61%降到~25%），说明低价模式也有天花板
- 淘宝的"价格力"战略（2024-2026）正在见效——百亿补贴+仅退款+直播电商正在收复失地
- 云计算的长期趋势不可逆转，阿里云在中国有先发优势

### ⚠️ 最终判定：护城河仍在但受损

**巴菲特的"又宽又深"标准，阿里目前只能算"宽但不深"。**
- 宽：业务覆盖面大、生态完善
- 不深：护城河不够深到让竞争对手无法攻入
- 潜在变数：如果AI（通义千问）+云能带来新的差异化优势，护城河可能重新加深

## ③ ROE历史（Return on Equity）

### 详细ROE计算

> 由于阿里有大量超额现金，ROE计算需要分"名义ROE"和"调整后ROE"

**名义ROE（归母净利润 / 归母权益）：**

| 财年 | 净利润 | 期初权益 | 期末权益 | 平均权益 | **名义ROE** |
|------|--------|---------|---------|---------|:----------:|
| FY2022 | 61,959 | — | ~925,600 | — | ~6.7% |
| FY2023 | 72,509 | ~925,600 | ~968,000 | ~946,800 | ~7.7% |
| FY2024 | 79,741 | ~968,000 | ~1,005,800 | ~986,900 | ~8.1% |
| FY2025 | 129,470 | ~1,005,800 | ~1,046,800 | ~1,026,300 | ~12.6% |
| FY2026 | 105,904 | ~1,046,800 | ~1,024,100 | ~1,035,450 | ~10.2% |

**调整后ROE（剔除超额现金，假设维持运营需要20%总资产现金）：**

| 财年 | 净利润 | 超额现金（估算） | 调整后权益 | **调整后ROE** |
|------|--------|:--------------:|:----------:|:------------:|
| FY2024 | 79,741 | ~1,200亿 | ~8,700亿 | ~9.2% |
| FY2025 | 129,470 | ~1,600亿 | ~8,900亿 | ~14.5% |
| FY2026 | 105,904 | ~500亿 | ~9,700亿 | ~10.9% |

### ROE拆解（杜邦分析）

$$
ROE = 净利润率 \times 总资产周转率 \times 权益乘数
$$

| 指标 | FY2025 | FY2026 | 变化 |
|------|:------:|:------:|:----:|
| 净利润率 | 13.0% | 10.3% | ↓ 恶化 |
| 总资产周转率 | ~0.45x | ~0.42x | ↓ 放缓 |
| 权益乘数 | ~2.1x | ~2.3x | ↑ 杠杆加大 |
| ROE | ~12.6% | ~10.2% | ↓ 恶化 |

> FY2026 ROE下降的主要驱动因素是**净利润率下降**（从13%到10.3%）。杠杆加大（权益乘数上升）说明公司在借钱投资，这增加了财务风险。

### 巴菲特的标准

巴菲特喜欢：
1. ROE持续>15%
2. ROE稳定（不大起大落）
3. 高ROE不是靠杠杆（高负债）堆出来的

**阿里不符合任何一条：**
- 均值~9%，不到15%
- 波动大（6.7%→12.6%→10.2%）
- 权益乘数在上升（靠加杠杆维持ROE）

### ⚠️ 最终判定：不达标

即使调整后ROE，也只有FY2025勉强触及14.5%，但FY2026又跌回11%以下。**ROE维度的结论很清楚：这不是巴菲特喜欢的"高回报企业"。**

**正面：** FY2024-2025两年合计回报股东~2,045亿，体现了"股东友好"姿态。FY2026分红增加也说明管理层愿意分享利润。

**负面：** FY2026回报骤降到413亿（-64%）。回购几乎归零。管理层说"要优先投资AI"，但投资者会问：为什么前两年能回购886亿，今年就不能了？

#### ❌ 运营效率（评分：4/10）

最大的红旗：**FY2026 SG&A从~1,660亿暴增到2,781亿（+67.5%）**。

这是一个巨大的管理失误信号：
- SG&A增长67.5%，营收只增长2.7%
- 每多花1元管理费用，只带来~0.04元额外营收
- 说明管理层在"撒钱式竞争"——靠补贴和营销费用硬抗PDD和抖音

> 巴菲特的芒格曾说过："当你发现管理层在烧钱保市场份额时，通常意味着企业已经失去了真正的竞争优势。"

#### ❓ 战略决策（评分：6/10）

| 决策 | 评价 |
|------|------|
| 1+6+N组织拆分 | ✅ **正确方向**——让各BU自负盈亏，提升效率 |
| 回归核心（出售银泰/大润发） | ✅ **正确**——组合在瘦身 |
| AI/云大规模投资（CapEx 1,261亿） | ⚠️ **方向对但节奏激进**——一次性烧太多现金 |
| 港股双重主要上市 | ✅ **正确**——降低地缘政治风险 |
| 蚂蚁IPO持续拖延 | ❌ **管理层对此被动应对**——缺乏前瞻性 |

### 管理层评估总结

**不是坏人，但可能是不太好的资本配置者。**

- 吴泳铭（CEO）：技术型人才，战略眼光没问题，但FY2026的利润率崩盘是他的第一份"不及格答卷"
- 蔡崇信（董事会主席）：财务出身（在阿里就是CFO出身），按理说应该更懂资本配置，但FY2026的现金消耗速度让人怀疑他的财务管理
- 好消息：阿里没有财务造假历史、没有欺诈丑闻、管理层持股比例合理（利益绑定）

### ⚠️ 最终判定：信号混杂

**"买阿里是因为管理层就买"——这句话目前说不出口。管理层在努力做对的事，但执行效果不佳。**

## ⑥ 安全边际（Margin of Safety）

### 格雷厄姆式安全边际计算

$$
安全边际 = \frac{内在价值 - 买入价}{内在价值} \times 100\%
$$

| 内在价值估算方法 | 估算值 | 安全边际 |
|-----------------|:-----:|:--------:|
| DCF（中性情景） | ~$120 | ~18% |
| 清算价值（保守） | ~$200 | ~51% |
| 分析师目标价 | ~$191 | ~48% |
| 3年平均PE(15x)×正常化利润 | ~$140 | ~30% |
| **综合** | **~$130-160** | **~25-38%** |

### 安全边际的四道防线

**第一道防线：低估的资产价值（PB 0.22x）**
- 即使阿里盈利能力归零，账上的净资产也远高于当前市值
- 但注意：阿里的"净资产"中包含商誉和无形资产（约2,000-3,000亿），这些在真正的清算中价值存疑

**第二道防线：强劲的经营现金流基础**
- 762亿经营现金流（FY2026），即使减去维持性CapEx（~400亿），仍有~360亿"真实FCF"
- 对应真实PE（经营现金流/市值）：~21x——不算特别便宜但可接受

**第三道防线：非核心资产价值缓冲**
- 蚂蚁集团(~33%)：估值~$600-800亿，阿里持有部分值~$200-260亿
- 菜鸟(~64%)：估值~$200-300亿
- 阿里健康+阿里影业+其他：~$50-100亿
- 合计非核心价值：~$450-660亿 —— 当前市值$2,246亿的20-29%

**第四道防线：回购期权**
- 董事会仍有~$310亿未执行回购额度
- 如果管理层继续回购，相当于在市场买入时自动提供价格支撑

### 安全边际的三大杀手

**杀手一：利润继续下滑**

如果FY2027利润再降20%（到~850亿）：
- 当前PE膨胀到 ~18.5x（还算合理）
- 但如果再降20%（到~680亿）：
- PE膨胀到 ~23x（不再便宜）

**杀手二：FCF持续为负**

如果FY2027继续负FCF（AI投资还在持续）：
- 净现金从569亿进一步下降
- 如果净现金归零，资产负债表刚性变差
- 如果转净负债，回购基本取消

**杀手三：中概股系统风险升级**

PB 0.22x本身就包含了"地缘政治折价"。如果发生：
- 中美审计纠纷升级（退市风险）
- 美国对中国科技公司加大投资限制
- 股价可以跌到PB 0.10x（~$45）
- 那时~50%跌幅——安全边际被击穿

### ⚠️ 最终判定：安全边际存在但不够"厚"

格雷厄姆喜欢50%+的安全边际（内在价值 vs 买入价）。巴菲特也偏好"足够厚的安全垫"。当前阿里巴巴的安全边际：
- 对保守投资者（要求50%+安全边际）：❌ 不够
- 对普通价值投资者（要求25-35%）：⚠️ 勉强够
- 对投机者（要求~10-15%）：✅ 够了

**但FY2026的利润恶化和FCF转负，让安全边际的真实厚度在收窄。如果FY2027能证明利润率企稳，安全边际会大幅增厚。**
