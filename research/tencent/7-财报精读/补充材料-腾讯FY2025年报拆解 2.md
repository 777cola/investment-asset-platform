## 一、利润表三维度拆解

### 1.1 收入-成本-利润链

```
收入 7,518亿（+13.9%）
  ├─ 收入成本 3,289亿（+5.6%）
  │    ├─ 带宽与服务器托管
  │    ├─ 内容成本（游戏分成、音乐版权、视频采购）
  │    ├─ 员工成本（研发+运营）
  │    └─ 渠道与支付成本
  │
  ├─ 毛利润 4,229亿（+21.1%） ← 毛利率 56.3%（+3.4pp）
  │
  ├─ 销售及市场费用 ~620亿（+4%）← 费用率下降
  ├─ 一般及行政费用 ~1,150亿（+8%）← 研发投入增加
  │
  ├─ 营业利润 2,456亿（+18.1%）← 营业利润率 32.7%
  │
  ├─ 其他收益/亏损（净额）~70亿
  ├─ 联营/合营公司利润 ~120亿
  ├─ 所得税 ~330亿（有效税率~13%）
  │
  └─ 净利润（归母）2,248亿（+15.9%）← 净利率 29.9%
```

### 1.2 费用率变化

| 费用项目 | FY2024（估） | FY2025（估） | 变化 |
|----------|-------------|-------------|------|
| 销售费用率 | ~9.2% | ~8.2% | -1.0pp（效率提升）|
| 管理费用率 | ~14.8% | ~15.3% | +0.5pp（AI研发投入）|
| 研发费用率 | ~10.5% | ~11.2%（估）| +0.7pp（混元+AI）|

**关键洞察：** 研发投入增加但销售费用下降——腾讯正从"花钱买用户"转向"花钱建能力"。

## 二、现金流量表深度拆解

### 2.1 经营现金流与净利润的对账

| 调节项目 | 金额（亿） | 说明 |
|----------|-----------|------|
| 净利润（归母） | 2,248 | 起点 |
| + 折旧摊销 | ~278 | EBITDA=2,734-2,456 |
| + 股份酬金 | ~230-280 | 非现金支出 |
| + 联营公司亏损（减收益）| ~-120 | 投资收益扣回 |
| + 营运资本变动 | ~-30 | 应收/应付变动 |
| + 其他调整 | ~50 | 减值、公允价值变动等 |
| **= 经营现金流** | **2,655** | 含金量极高 |

### 2.2 自由现金流（FCF）计算

```
经营现金流       2,655亿
- 资本支出         499亿（AI基础设施为主）
- 租赁负债偿还      40亿（估）
= 自由现金流      2,116亿（口径一）
≈ 自由现金流      2,156亿（公司口径）
```

### 2.3 FCF分配去向

## 三、资产负债表细节

### 3.1 资产结构（US$亿）

```
总资产 US$2,836亿
├─ 流动资产
│   ├─ 现金及等价物     US$597亿（21%）
│   ├─ 应收账款         ~US$150亿（5%）
│   └─ 其他流动资产     ~US$200亿（7%）
├─ 非流动资产
│   ├─ 联营/合营投资     ~US$340亿（12%）
│   ├─ 公允价值投资     ~US$480亿（17%）
│   ├─ 固定资产（PPE）   ~US$420亿（15%）
│   ├─ 无形资产+商誉    ~US$520亿（18%）
│   └─ 其他非流动资产    ~US$129亿（5%）
```

### 3.2 负债结构（US$亿）

```
总负债 US$1,110亿
├─ 流动负债
│   ├─ 应付账款         ~US$250亿
│   ├─ 短期借款         ~US$30亿
│   └─ 递延收入         ~US$200亿（游戏预充值等）
├─ 非流动负债
│   ├─ 长期债务         US$465亿
│   └─ 其他非流动负债     ~US$165亿
```

### 3.3 关键比率计算

| 比率 | 公式 | 结果 | 安全阈值 |
|------|------|------|---------|
| 流动比率 | 流动资产/流动负债 | ~2.1× | >1.5 |
| 速动比率 | (流动资产-存货)/流动负债 | ~1.9× | >1.0 |
| 现金比率 | 现金/流动负债 | ~1.2× | >0.5 |
| 债务/EBITDA | 总债务/EBITDA | ~1.1× | <3.0 |
| 利息保障倍数 | EBIT/利息费用 | >15× | >5.0 |

## 五、AI战略影响量估（混元大模型）

### 5.1 AI对业务的量化贡献

| 业务线 | AI赋能方式 | 对FY2025增量贡献（估） |
|--------|-----------|----------------------|
| 广告 | AI驱动定向投放 → eCPM提升 | +50-80亿广告收入 |

- 静态回报周期：**~1.2-1.5年**
