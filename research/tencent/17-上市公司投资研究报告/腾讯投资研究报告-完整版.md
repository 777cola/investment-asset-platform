## 1. 公司概况

### 1.1 历史沿革

腾讯控股有限公司成立于1998年11月，由马化腾、张志东、曾李青、许晨晔、陈一丹共同创办。公司于2004年6月在香港联交所主板上市（股票代码：00700.HK），2019年以存托凭证形式在OTC市场交易（代码：TCEHY.US）。

**发展历程里程碑：**

| 阶段 | 时间 | 关键事件 |
|------|------|----------|
| 创立与萌芽期 | 1998-2003 | OICQ上线（1999）、QQ注册用户突破1亿（2001） |
| 上市成长期 | 2004-2010 | 港交所上市（2004）、QQ同时在线突破1亿（2010） |
| 移动互联网转型 | 2011-2013 | 微信发布（2011.1）、微信支付上线（2013.8） |
| 生态扩张期 | 2014-2017 | 投资京东、美团、拼多多；王者荣耀上线（2015） |
| 产业互联网深化期 | 2018-2020 | 腾讯云战略升级、小程序生态成熟、视频号上线（2020） |
| AI与出海战略期 | 2021至今 | 混元大模型发布、游戏全球布局深化、视频号商业化加速 |

### 1.2 股权结构（截至2026年6月）

| 股东类型 | 持股比例 |
|----------|----------|
| 创始人及管理层（内部持股） | 7.91% |
| 机构投资者 | 24.27% |
| 公众股东（含港股通） | 67.82% |

**主要股东：**

**治理结构：** 采用"同股同权"架构，创始人团队通过直接持股而非特殊投票权实施控制，治理透明度高，代理风险较低。

### 2.2 中国互联网行业发展趋势

**趋势一：流量红利见顶，进入存量深耕时代**
中国互联网用户渗透率已超78%，新增用户空间有限。行业竞争焦点从"获客"转向"单用户价值提升（ARPU）"和"生态黏性"建设。头部平台通过超级App战略构建生态闭环，跨场景打通用户行为数据，提升商业化效率。

**趋势二：AI大模型重塑行业格局**
生成式AI正在深刻改变互联网的产品形态和商业模式。应用层涵盖AI搜索、AI社交、AI内容创作、AI客服等场景。腾讯混元大模型已全面嵌入微信搜索、腾讯广告、企业微信等核心产品，AI对广告点击率（CTR）和变现效率的贡献在FY2025已提升至约15%。

**趋势三：游戏出海进入收获期**
中国游戏厂商在全球市场份额从2020年的20%提升至2025年的29%。腾讯通过自研工作室群（天美、光子、魔方、北极光）+ 投资并购（Riot Games、Supercell、Epic Games、Ubisoft）双轮驱动，已成为全球游戏收入第一的公司。海外游戏收入占比在FY2025已提升至31%。

**趋势四：企业级SaaS与云计算高速增长**
中国企业数字化率仍偏低（中小企业上云率约40%），市场空间广阔。腾讯云定位"产业互联网"，聚焦金融、零售、政务、医疗等行业。

**趋势五：视频号与短视频商业化加速**
视频号DAU在FY2025已突破6亿，成为微信生态内最重要的流量增长点和商业化引擎。视频号广告收入、直播电商GMV均处于高速增长阶段。

### 2.3 政策与监管环境

| 维度 | 现状 | 影响评估 |
|------|------|----------|
| 反垄断监管 | 2021年强监管后已进入常态化阶段 | 对大型平台扩张性投资有约束，但核心业务影响有限 |
| 游戏版号 | 2023年以来常态化发放，节奏稳定 | 利好游戏供给端和新品上线节奏 |
| 数据安全/隐私 | 《数据安全法》《个人信息保护法》全面实施 | 合规成本上升，但利好头部平台生态 |
| 金融科技监管 | 支付业务整改完成，金融控股公司架构落地 | 不确定性基本消除，格局稳定 |
| AI监管 | 《生成式AI管理办法》实施（2023.8） | 强调备案制+内容安全，合规成本可控 |
| 未成年人保护 | 游戏防沉迷系统已全面实施 | 短期有一定冲击，长期利好行业健康发展 |

**总体判断：** 监管环境已从"强风暴"进入"常态化"阶段，腾讯主要业务的政策不确定性已大幅下降。2025年政府工作报告明确提出"促进平台经济健康发展"，政策基调转向支持。

## 3. 商业模式

### 3.1 业务架构概览

腾讯的商业模式可以概括为"**社交护城河 → 流量分发 → 多元变现**"的三层架构：

```
                 ┌──────────────────────┐
                 │  微信/QQ（13.5亿DAU）  │ —— 社交护城河（免费）
                 └──────────┬───────────┘
                            │
                    ┌───────┴───────┐
                    │   流量分发     │
                    └───────┬───────┘
                            │
          ┌─────────────────┼─────────────────┐
          ▼                 ▼                  ▼
    ┌──────────┐    ┌───────────┐     ┌───────────┐
    │  游戏    │    │ 金融科技   │     │   广告    │
    │  ~49%    │    │  ~32%      │     │  ~18%     │
    └──────────┘    └───────────┘     └───────────┘
          │                │                │
          ▼                ▼                ▼
    ┌──────────┐    ┌───────────┐     ┌───────────┐
    │ 自研+代理 │    │支付+理财+ │     │ 社交+视频 │
    │ 全球发行  │    │ 微众银行  │     │ +小程序   │
    └──────────┘    └───────────┘     └───────────┘
```

### 3.2 业务板块详细分析

#### 3.2.1 增值服务（占总收入~49%）

**游戏业务（核心利润引擎）：**
- **国内游戏：** 王者荣耀（年流水~300亿）、和平精英、金铲铲之战、英雄联盟手游等核心IP持续贡献稳定现金流。2025年推出《王者荣耀：世界》《三角洲行动》等新大作，带动国内游戏收入同比增长12%。
- **国际游戏：** Supercell（《荒野乱斗》《部落冲突》）、Riot Games（《英雄联盟》《无畏契约》）、Epic Games（《堡垒之夜》）构成海外收入基本盘。2025年海外游戏收入同比增长18%，收入占比31%。
- **竞争优势：** 全球最大游戏公司（按收入计），拥有最丰富的IP储备和最强大的发行管道。

**社交网络：** 包括直播打赏分成（虎牙、斗鱼、视频号直播）、QQ会员、QQ音乐、腾讯视频订阅等。受短视频冲击和内容成本影响，该分部增长相对平稳。

#### 3.2.2 金融科技与企业服务（占总收入~32%）

**微信支付（核心现金流业务）：**
- 日均交易笔数超20亿，中国移动支付市场份额约40%，仅次于支付宝。
- 收入来自商户交易费率（约0.38%）、提现手续费、以及金融产品代销（理财通等）。
- 利润率持续改善，FY2025该分部毛利率已提升至45%+。

**腾讯云与企业服务：**
- 中国云计算市场份额第三（约12%），仅次于阿里云（34%）和华为云（19%）。
- 差异化优势在于PaaS/SaaS层：企业微信连接超1500万家企业，腾讯会议、腾讯文档、企点等SaaS产品协同效应显著。
- 策略上主动放弃低利润的CDN等IaaS业务，聚焦高毛利的PaaS和行业解决方案。

#### 3.2.3 广告业务（占总收入~18%）

- **驱动引擎：** 视频号广告是最大增量——视频号广告收入FY2025同比增长超过60%，成为公司收入增长最快的业务。
- **技术赋能：** 混元大模型赋能广告系统，实现AI智能定向投放、素材自动生成，CTR提升约15%-20%。
- **增长空间：** 目前视频号广告加载率约5%，远低于抖音（约15%）和快手（约12%），提升空间巨大。中期目标加载率提升至8%-10%。

**关键趋势解读：**

1. **收入增长恢复：** FY2022因宏观逆风和游戏版号停发导致收入同比-1%，之后连续3年恢复增长。FY2025增速提升至13.9%，主要驱动力为视频号广告、国际游戏和FBS业务。

2. **毛利率持续改善：** 毛利率从FY2021的43.9%提升至FY2025的56.3%，提升幅度达12.4个百分点。核心驱动因素：低利润业务（音乐直播、云CDN）主动收缩；高利润业务（视频号广告、微信支付、游戏）占比提升。

3. **利润结构优化：** Non-IFRS净利率从FY2023的18.9%低点回升至FY2025的29.9%，反映公司盈利能力已摆脱监管周期和投资损失的拖累。

#### 杜邦分解分析（ROE）

| 年份 | ROE | = | 净利率 | × | 资产周转率 | × | 权益乘数 |
|------|-----|---|--------|----|-----------|----|---------|
| FY2021 | ~25.3% | | 40.1% | | 0.33x | | 1.91x |
| FY2022 | ~21.8% | | 33.9% | | 0.31x | | 2.07x |
| FY2023 | ~15.8% | | 18.9% | | 0.33x | | 2.53x |
| FY2024 | ~18.5% | | 29.4% | | 0.31x | | 2.03x |
| FY2025 | 20.51% | | 29.9% | | 0.33x | | 2.08x |

**杜邦分析结论：**
- **净利率**是ROE波动的主要来源，FY2023因投资损失（美团、京东减持）导致净利率异常低，目前已经恢复。
- **资产周转率**保持稳定（0.31-0.33x），属于轻资产互联网公司的典型水平。
- **权益乘数**有所下降（从2.53x降至2.08x），反映公司债务管理更加稳健。
- **整体趋势：** ROE正从FY2023的低点回升至20%以上，处于优质企业的健康水平。

## 6. 成长驱动

### 6.1 短期驱动力（FY2026-FY2027）

#### ① 视频号商业化加速

|------|---------|---------|---------|
| 视频号DAU（亿） | ~6 | ~6.5 | ~7 |

| 视频号广告收入（亿人民币） | ~400 | ~600 | ~780 |
