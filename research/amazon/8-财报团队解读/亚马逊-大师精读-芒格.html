核心判断

芒格读财报的方法是反过来：先假设这份财报想让你得出一个错误结论，然后找出它是怎么做到的。这份财报想让你记住“利润率 13.9% 创历史新高”。那么，它藏了什么？

四个“被藏起来”的事实
表面说法藏在哪真实含义
营业利润率 13.9% 创新高技术与基础设施费用 +20.2%折旧刚开始爬坡，成本还没到顶
净利润 206.85 亿其他收入 -7.03 亿；去年同期 +101.86 亿净利同比 -2.4% 是基数效应，不是经营恶化
前三季净利翻倍（+101%）其他收入 683.59 亿占税前 46%翻倍的是 Anthropic 估值，不是生意
AWS 增速 39.3% 创五年最快Azure +48%、Google Cloud +103%它是最快的自己，不是最快的行业
对比数据：Alphabet 2026Q3（10/28 发布）Google Cloud 收入 307.09 亿、同比 +103%；微软 2026Q3（10/29 发布）Azure 同比 +48%。
第一个隐藏项：折旧的时钟刚开始走

技术与基础设施费用 348.14 亿、同比 +20.2%，前三季 +23.3%，是费用表里增长最快的一行。这一行里装着 AWS 的服务器折旧、数据中心租金和技术人力。2026 年 2,200 亿资本开支，按 5–6 年直线折旧，从 2027 年开始每年多出 370–440 亿折旧。

所以“13.9% 的营业利润率是历史最高”这句话，准确的说法是“在折旧还没上来的窗口期，它是历史最高”。窗口期大约还有四到六个季度。这就是芒格式的读法：不是问“有多好”，是问“好在什么条件下”。

第二个隐藏项：它不再是增速最快的那家云

AWS 39.3% 是它自己近五年最快，但同期 Azure +48%、Google Cloud +103%（307 亿收入、翻倍）。“连续六季加速”是一个真实的、值得敬佩的事实，但它不等于“赢得竞争”。在一个整体增速 40%+ 的行业里，39.3% 意味着份额在缓慢流失。

芒格会说：好消息是这门生意足够大，三家都能增长；坏消息是当增长放缓时，最先被压价的是规模最大、迁移成本最高的那家——因为客户知道你不会为了价格放弃一个用了十年的云。规模优势在需求旺盛时是护城河，在需求转弱时是提款机。

结论

精读结论：这份财报没有说谎，但它挑了最好的角度。营业利润率新高是真的，折旧还没上来也是真的；净利下滑是基数效应，但浮盈撑着前三季的“翻倍”也是真的。芒格会给的评语大概是：“一家好公司，一份被精心编排过的财报。买它，但要按最坏的口径算一遍。”
