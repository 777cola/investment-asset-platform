# 亚马逊 (AMZN) 财务与行情数据

- 数据截止日：2026/11/06
- 收盘价：259.3 USD
- 市值：约 2.80 万亿美元
- 估值：PE(TTM) 约 20.8x

## 核心指标

- 2026Q3 净销售额：2,019.4 亿美元（同比 +12%）（略低于市场预期）
- Q3 营业利润：280.8 亿美元（同比 +61%）（营业利润率 13.9%，历史最高）
- AWS 收入：459.8 亿美元（同比 +39.3%）（近五年最快，连续六季加速）
- AWS 营业利润：177.8 亿美元（利润率 38.7%）（贡献集团六成以上营业利润）
- AWS 在手订单：5,780 亿美元（同比三位数增长）（2027–2028 产能已被预订）
- Q3 资本开支：772.6 亿美元（同比 +120%）（高出市场预期三成）
- TTM 自由现金流：-424 亿美元（上年 +148 亿）（连续两季为负）
- 北美零售营业利润率：7.7%（上年同期 4.3%）（零售利润率的结构性抬升）
