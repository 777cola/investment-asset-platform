本地生活與餐飲產業鏈全景

美團（3690.HK / MPNGY）— 本地生活服務 / 科技零售
研究日期：2026-07-07 | 資料來源：MacroTrends、Google Finance、Stock Analysis、公開資訊

📋 報告摘要

美團作為中國最大的本地生活服務平臺，其業務橫跨餐飲外賣、到店餐飲、酒店旅遊、即時零售等多個產業鏈。本報告從產業鏈全景視角，系統梳理美團在各條產業鏈中的定位、價值創造機制、利潤分配格局及未來演變趨勢。

維度核心發現
產業鏈覆蓋本地生活全鏈條：需求端（消費者）→ 平臺（美團／點評）→ 供給端（商戶）→ 配送端（騎手）→ 履約端
核心護城河即時配送網路（日均數百萬單）+ 商戶生態系統（600萬+活躍商戶）+ 使用者規模（6億+年活躍使用者）
利潤分配特徵平臺方攫取產業鏈最大價值（佣金+廣告），配送端持續虧損（補貼騎手），供給側利潤承壓（高佣金率）
成長引擎即時零售（美團閃購／小象超市）> 海外擴張（Keeta）> 到店酒旅復甦 > 外送穩定成長
競爭格局外送領域絕對領先（約70%份額）；到店業務面臨抖音激烈競爭；即時零售全面開戰（阿里、京東、字節）

1️⃣ 本地生活服務產業鏈全鏈條

1.1 產業鏈總覽

需求端 → 流量入口 → 平臺撮合 → 供給端 → 履約配送 → 售後服務

美團的本地生活服務產業鏈可概括為「六層模型」：

層環節參與者美團的角色
L1需求端（消費者） C 端使用者（6 億以上年活躍使用者） App／小程式入口、推薦演算法、會員體系（美團會員／神會員）
L2流量入口 美團 App、大眾點評 App、微信支付九宮格、小程式 超級應用程式生態 + 微信流量合作
L3平臺撮合 美團平臺（演算法匹配、智慧調度、評價系統） 核心平臺：資訊撮合 + 交易擔保 + 信用體系
L4供給端（商戶） 餐廳（900萬+）、酒店（約140萬）、零售店、景區等 SaaS系統（美團管家／快驢進貨）、廣告投放、流量分配
L5履約配送 美團外送騎手（約700萬註冊騎手）、美團配送網路 自建即時配送網路（美團配送），開放平臺（眾包＋專送）
L6售後服務 客服系統、退款／投訴、評價體系 美團客服 + 大眾點評評價系統

1.2 產業鏈價值流

整個產業鏈的價值流動方向：

  • 資金流：消費者 → 平臺（美團）→ 商戶（85-90%）+ 騎手（配送費）→ 美團留成（佣金+廣告）
  • 資訊流：使用者評價 → 平臺演算法 → 商戶營運決策 → 服務改進 → 口碑傳播
  • 物流：商戶／倉庫 → 配送中心／騎手 → 消費者

2️⃣ 餐飲外送產業鏈

2.1 產業鏈結構

餐廳（食材採購＋烹飪） → 平臺（美團／餓了麼） → 騎手（配送網路） → 消費者

2.2 各環節詳細分析

環節角色成本／收入結構美團競爭力
餐廳 餐品製作方，承擔食材成本（30-40%）+ 租金（10-20%）+ 人工（15-25%） 商戶實收=訂單價×（1-平臺佣金率15-25%）；外送毛利率通常低於內用 提供SaaS工具（美團管家）、快驢進貨（B2B供應鏈），幫助商戶降本增效
平臺 資訊撮合+交易擔保+流量分配 收入來源：佣金（單均約4-5元）＋廣告（CPC/CPM）；成本：研發（約佔營收6%）＋銷售（約佔營收22%） 市佔率約 70%（對比餓了麼約 25%）；日均訂單約 6000 萬單；雙邊網路效應極強
騎手 最後一公里配送核心 單均配送費約 5-8 元（平臺支付）；月收入約 5000-10000 元（一線城市）；註冊騎手約 700 萬 美團配送：自建加眾包混合模式；日活騎手約100萬；智慧調度系統優化路線
消費者 需求方，追求便利與性價比 客單價~45-60元；配送費~3-5元（部分減免）；年下單頻次~40-60次 美團會員體系（神會員）提升黏性；覆蓋全國2800+縣市區

2.4 外送面臨的挑戰

  • 外送員社會保險合規多平臺靈活就業政策日趨嚴格，若強制要求為騎手繳納社保，單均成本可能增加1-3元
  • 反壟斷監管「二選一」被禁後，商戶多平臺經營成為常態，餓了麼、抖音外賣對優質商戶的爭奪加劇
  • 配送效率瓶頸：單均配送時間已壓縮至30-40分鐘，進一步優化空間有限

3️⃣ 到店／酒店旅遊產業鏈

3.1 到店業務產業鏈

線下商戶（餐廳／酒店／景區） → 平臺（大眾點評／美團） → 流量入口 → 消費者到店消費

3.2 到店酒旅與外送的產業鏈差異

維度到店／酒店旅遊外送
履約方式消費者到店（輕資產）平臺配送到家（重履約）
平臺抽成2-10%（佣金+廣告）15-25%（包含配送）
毛利率~70-80%~30-40%
利潤率極高（純平臺模式）低（配送成本拖累）
競爭強度抖音團購／口碑激烈競爭餓了麼追趕，但格局穩定
使用者決策評價驅動（大眾點評核心護城河）價格＋速度驅動
美團護城河海量真實評價（數億條）配送網路（700萬騎手）

3.3 到店業務產業鏈特徵

  • 高毛利現金牛：到店業務是美團的利潤核心，貢獻了遠超其營收佔比的利潤。純平臺撮合模式，無需配送網路，邊際成本極低。
  • 大眾點評的護城河大眾點評累積的數億條真實使用者評價，構成難以複製的資料護城河。抖音雖然透過短影音衝擊到店市場，但評價體系的深度與可信度短期內難以超越。
  • 抖音衝擊：抖音以「內容即廣告」模式衝擊到店市場，2024年抖音到店GMV超$300億，對美團到店業務形成直接競爭。但美團的應對策略（直播+達人探店）正在縮小差距。
  • 酒店旅遊：美團以中低端酒店（三四線城市）為切入點，逐步向中高端滲透。2024年酒店間夜量持續增長，但客單價低於攜程。產業鏈中美團連接的是中小型酒店／民宿。

3.4 到店酒旅收入利潤貢獻估算

業務營收佔比（估算）利潤佔比（估算）營業利益率
到店／酒店旅遊~18-20%~50-60%~30-40%
外送~55-60%~20-30%~3-5%
新業務（優選／閃購等）~22-28%虧損或微利負或低單位數
💡 核心洞察：到店酒旅以不到20%的營收，貢獻了超過50%的利潤，是美團真正的「利潤引擎」。外送的高GMV背後是低利潤率，本質上是「引流＋獲客」工具。到店業務的護城河（評價體系）是美團最核心的長期競爭壁壘。

4.1 即時零售三駕馬車

業務線模式品類履約時效發展階段
美團閃購 平臺模式（商戶→消費者） 超市便利、醫藥、3C數位、鮮花、美妝 30分鐘-1小時 快速成長，2025年GMV預計約500億美元

4.2 即時零售產業鏈結構

品牌商／供應商 → 零售商／前置倉 → 美團閃購／小象超市平臺 → 騎手配送 → 消費者

4.3 各環節分析

環節參與者盈利模式美團優勢／挑戰
品牌商／供應商 聯合利華、寶僑、可口可樂、本地經銷商 按批發價供貨，利潤取決於終端定價 美團幫助品牌商觸達即時消費場景，但中間環節效率待提升
零售商／前置倉 永輝、沃爾瑪、屈臣氏（閃購合作）+ 小象超市自營 閃購：平臺佣金率10-20%；小象：自營毛利率15-25% 閃購合作商家超過20萬家；小象自營虧損收窄中
平臺 美團閃購／小象超市／美團優選 閃購：佣金＋廣告；小象：商品差價；優選：佣金 依託外送配送網路，邊際成本優勢；但品類擴張需要時間
配送 美團騎手（與外送共用網路） 單均配送費＋時段補貼 重複使用外送配送網路，尖峯時段可調配運力，效率遠高於自建物流

4.4 即時零售競爭格局

競爭者模式優勢劣勢
美團閃購 平臺＋自有配送 配送網路成熟、商戶資源豐富、使用者基數大 非標品營運能力弱於電商平臺
京東到家（達達） 平臺＋達達配送 京東流量、供應鏈能力強 配送密度不及美團
阿里（餓了麼+盒馬+天貓超市） 平臺+自營+即時配送 全品類覆蓋、供應鏈深厚 各業務協同不足
抖音即時零售 內容＋即時配送 流量巨大、內容行銷 配送網路依賴第三方

4.5 美團優選產業鏈特點

  • 供應鏈產地直採+中心倉+網格倉+團長自提點，層級較多
  • 盈利困境：社區團購毛利極低（<10%），履约成本高，多数市场参与者亏损
  • 美團調整2024-2025年持續收縮虧損區域，聚焦高密度城市，向「品質團購」轉型
  • 競爭：拼多多（多多買菜）在社區團購領域成本控制更優，美團優選市場份額第二
💡 核心洞察：即時零售是美團「無界零售」戰略的核心——將外送配送能力延伸到萬物到家。美團閃購的GMV增速（~40%）遠高於外送（~10%），是下一個成長引擎。小象超市（前置倉）是美團在生鮮領域對抗盒馬／叮咚買菜的核心武器。這三條業務線共享配送網路，形成了顯著的範疇經濟效應。

產業鏈環節與國內的差異美團的策略

配送端（騎手） 沙烏地以外籍勞工為主，巴西則以本土騎手為主 借鑑中國外送管理經驗，本地化招聘與培訓；運用中國成熟的智慧調度系統

5.3 海外擴張面臨的產業鏈挑戰

  • 配送網路從零搭建：海外沒有中國這樣密集的勞動力供給，騎手招募和管理成本更高
  • 本地化營運：沙烏地餐飲習慣（齋月、女性限制）、巴西物流基礎設施差異，需要深度本地化
  • 資本消耗：海外擴張需要大量補貼投入，短期內對財務報表形成拖累
  • 監管風險中東勞動法、巴西稅務體系、資料本地化要求等
💡 核心洞察：海外擴張是美團尋找第二成長曲線的策略舉措。Keeta 本質上是在輸出中國的外送產業鏈能力——智慧調度系統（AI演算法）、配送網路管理經驗、平臺營運方法論。沙烏地阿拉伯和巴西的本地外送市場格局尚未固化，美團有機會複製美團在中國成功的模式。但海外擴張的不確定性高，短期不宜高估其收入貢獻（2025年海外收入佔比預計<3%）。

利潤最肥美環節 TOP3（美團視角）：

2️⃣ 社區團購— 持續虧損中，低毛利＋高損耗＋高履約成本
3️⃣ 海外擴張（Keeta）— 策略性虧損期，補貼投入大

7️⃣ 產業鏈變化趨勢與美團的影響力

7.1 產業鏈五大變化趨勢

趨勢一：從「餐飲外送」到「萬物到家」

美團正在將外送的即時配送能力延伸到所有品類（醫藥、3C、美妝、酒水等）。這一趨勢的產業鏈含義：

  • 品類邊界消失：傳統電商與本地零售的界限模糊，「30分鐘達」成為新標準
  • 物理倉網重構：品牌商需要在全國建立「前置倉」網路，而非僅依賴中心倉發貨
  • 美團角色變化：從餐飲平臺升級為「本地零售基礎設施」，成為品牌商觸達消費者的新管道

趨勢二：AI 重塑產業鏈效率

  • 智慧排程：AI演算法優化騎手路線，減少空駛率（10%→5%），單均配送成本可降0.5-1元
  • 智慧推薦：千人千面的搜尋／推薦，提升轉換率（預計提升10-20%）
  • 無人配送：自動駕駛＋機器人配送（2025年部分區域試點），長期可顯著降低人力依賴
  • 智慧定價：動態定價模型，優化峯谷訂單分佈，提升運力利用率

趨勢三：商戶生態從「流量依賴」到「數位化營運」

  • 美團從流量平臺向「商戶數位化助手」轉型：SaaS（美團管家）+ 供應鏈（快驢進貨）+ 金融（美團生意貸）
  • 商戶對美團的黏性從「獲客」延伸至「全鏈路經營」，護城河加深
  • 快驢進貨（B2B食材供應鏈）2024年GMV約80-100億美元，市場份額提升中

趨勢四：政策監管重塑利潤分配

  • 騎手權益：職業傷害保障（2022年開始試點）、社保合規化趨勢，成本從平臺流向供給端
  • 佣金透明化：監管要求平臺明確分開技術服務費與配送費，商戶議價能力增強
  • 反壟斷常態化「二選一」禁止後，多平臺經營成為常態，美團需要透過服務而非強制排他性維持商戶留存

趨勢五：下沉市場與銀髮經濟

  • 三四線城市及農村地區的外送滲透率仍低（<30%），是长期增长空间
  • 銀髮羣體（60歲以上）的本地生活需求未被充分挖掘，適老化App＋大字版＋社區服務
  • 美團優選的「次日自提」模式在下沉市場有獨特價值（低價＋社區團長信任）

8️⃣ 策略總結：產業鏈視角下的美團投資價值

✅ 核心優勢（產業鏈角度）
  • 雙邊網路效應牢固：消費者越多→商戶越多→配送密度越高→體驗越好→消費者越多，正向飛輪已形成
  • 基礎設施型平臺：美團已成為中國本地生活的「水電煤」基礎設施，替代成本極高
  • 範疇經濟效應：外送、閃購、小象共享配送網路，邊際成本遞減速度加快
  • 利潤引擎強勁：到店／酒旅／廣告構成高毛利利潤池，支撐外送＋海外的前期投入
⚠️ 核心劣勢（產業鏈角度）
  • 外送配送盈利難題：配送成本剛性化＋競爭壓力，單均利潤空間有限
  • 主業增速放緩：外送滲透率接近天花板（一二線城市），9.4%的營收增速難以支撐高估值
  • 到店護城河受侵蝕：抖音內容攻勢兇猛，大眾點評的「評價護城河」在短影音時代面臨挑戰
  • 新業務仍需時間：即時零售／海外／優選均需持續投入，盈利拐點不確定
