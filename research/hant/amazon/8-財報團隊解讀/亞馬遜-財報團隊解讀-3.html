核心判斷

蒙格讀財報的方法是反過來：先假設這份財報想讓你得出一個錯誤結論，然後找出它是怎麼做到的。這份財報想讓你記住「利潤率 13.9% 創歷史新高」。那麼，它藏了什麼？

四個「被藏起來」的事實
表面說法藏在哪裡真實含義
營業利益率 13.9% 創新高技術與基礎設施費用 +20.2%折舊剛開始爬坡，成本還沒到頂
稅後淨利 206.85 億其他收入 -7.03 億；去年同期 +101.86 億稅後淨利同比 -2.4% 是基數效應，不是經營惡化
前三季稅後淨利翻倍（+101%）其他收入 683.59 億占稅前 46%翻倍的是 Anthropic 估值，不是生意
AWS 增速 39.3% 創五年最快Azure +48%、Google Cloud +103%它是最快的自己，不是最快的行業
對比數據：Alphabet 2026Q3（10/28 發布）Google Cloud 收入 307.09 億元、同比 +103%；微軟 2026Q3（10/29 發布）Azure 同比 +48%。
第一個隱藏項：折舊的時鐘剛開始走

技術與基礎設施費用 348.14 億、同比 +20.2%，前三季 +23.3%，是費用表裡增長最快的一行。這一列裡裝著 AWS 的伺服器折舊、資料中心租金和技術人力。2026 年 2,200 億資本開支，按 5–6 年直線折舊，從 2027 年開始每年多出 370–440 億折舊。

所以「13.9% 的營業利益率是歷史最高」這句話，準確的說法是「在折舊還沒上來的窗口期，它是歷史最高」。窗口期大約還有四到六個季度。這就是蒙格式的讀法：不是問「有多好」，是問「好在什麼條件下」。

第二個隱藏項：它不再是增速最快的那家雲

AWS 39.3% 是它自己近五年最快，但同期 Azure +48%、Google Cloud +103%（307 億收入、翻倍）。「連續六季加速」是一個真實的、值得敬佩的事實，但它不等於「贏得競爭」。在一個整體增速 40%+ 的行業裡，39.3% 意味著份額在緩慢流失。

芒格會說：好消息是這門生意足夠大，三家都能增長；壞消息是當增長放緩時，最先被壓價的是規模最大、遷移成本最高的那家——因為客戶知道你不會為了價格放棄一個用了十年的雲。規模優勢在需求旺盛時是護城河，在需求轉弱時是提款機。

結論

精讀結論：這份財報沒有說謊，但它挑了最好的角度。營業利益率新高是真的，折舊還沒上來也是真的；淨利下滑是基期效應，但浮盈撐著前三季的「翻倍」也是真的。蒙格大概會給的評語是：「一家好公司，一份被精心編排過的財報。買它，但要按最壞的口徑算一遍。」
